## Tutorial/what to do

1: download the files and extract them

2: put the files in the .config file 

3: make sure you have the respective apps needed 

4: refresh your i3 (mod + shift + R)

(make sure to replace user with your name for some of the config files prolly 1 or 2)

## APPS 
helix, alacritty, i3-wm, dmenu, fish(shell), fastfetch, xsetroot,i3status

(ps: make sure you have "exec i3" in your "~/.xinitrc" file also quick heads up it doesnt have brightness keybinds so if u want brightness control you have to get brightnessctl)
